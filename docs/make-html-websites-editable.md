# Make HTML websites editable in WordPress with Tahmir AI Pro

Start with the HTML website or AI-built page your team has approved. **Tahmir AI Free imports and displays supported pages; the visual editing workflow requires the separate licensed Pro add-on.** See [Pro benefits and upgrade options](https://www.tahmir.com/upgrade/).

## Import with Free, then add Pro

1. Install [Tahmir AI Free](../README.md#download-and-install-the-free-converter-plugin).
2. Import a supported HTML ZIP or deployed public website URL.
3. Review the imported design and confirm that routes, assets and scripts work.
4. Install Tahmir AI Pro alongside Free and activate a valid license.
5. Open the visual editor for a supported imported page; make one real text/image update and verify the saved result.
6. In **Manage**, review logo detection/replacement and shared-menu controls.
7. Define client roles, demonstrate routine changes and approve the site before publishing.

Imported pages and form data carry over, so the upgrade does not require importing again. The Tahmir editor is the editing interface; this workflow does not promise automatic conversion to Gutenberg blocks, Elementor widgets or a new WordPress theme.

For a portfolio, ask the editor to open a second project from the homepage. The [Framer portfolio walkthrough](https://www.tahmir.com/how-to-convert-a-framer-website-to-wordpress/) shows how to give each project a WordPress page and check that its card opens the right one.

## Changes the team can prepare with Pro

| Need after import | Pro workflow |
| --- | --- |
| Change copy, images and calls to action | Visual editor and page modules |
| Replace branding across supported page locations | Detect and replace logos in Manage |
| Update shared navigation | Menu management for supported imported menus |
| Maintain lead capture | Form editing, entries, notifications and integrations |
| Prepare launch details | SEO/AI-search tools and client delivery tools |
| Refine generated content | Optional AI tools; provider setup or credits may apply |

Editing support depends on the imported structure and the feature being used. Test custom scripts, embeds, complex application behavior and protected content separately. For GoHighLevel, CRM workflows and calendars remain integrations; for Lovable, backend data/authentication remain application scope.
