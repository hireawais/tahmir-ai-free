# GoHighLevel to WordPress: move supported website and funnel pages

Tahmir AI Free provides a public-URL workflow for bringing supported GoHighLevel website or funnel pages into WordPress. Start with a published page you own or are authorized to migrate. See Tahmir's official [GoHighLevel to WordPress converter guide](https://www.tahmir.com/gohighlevel-to-wordpress-converter/).

## Plan the migration before importing

List the public page URLs, images, downloads, navigation destinations and lead-capture actions that the client uses. Select one representative page to test. Record the parts that depend on HighLevel, such as calendars, embedded forms, membership access, CRM actions and payment flows.

The Free plugin imports supported visible page content and assets. It does not transfer a GoHighLevel account, contacts, opportunities, pipelines, workflow automations, conversations, appointments, membership data or checkout logic.

## Import a GoHighLevel page into WordPress

1. Publish the source page and verify its public URL without signing in.
2. Install [Tahmir AI Free](../README.md#download-and-install-the-free-converter-plugin) on the destination WordPress site.
3. Open **Tahmir AI → Import → Import from URL** and enter the page URL.
4. Review discovered pages, import the required pages and open the WordPress result.
5. Compare desktop/mobile layout, imagery, headings, calls to action and navigation.
6. Reconnect or replace integrations and test a real submission or booking from start to finish.
7. Prepare redirects for any changed URLs before switching the domain or publishing.

An HTML ZIP is another option when you already have a supported static export and its assets. Do not assume HighLevel provides an HTML export for every page type. HighLevel's own [funnel/website import feature](https://help.gohighlevel.com/support/solutions/articles/48001209319-converting-funnels-and-websites-with-the-new-import-feature) is an internal page-copy workflow; it is separate from this WordPress migration.

## Forms, calendars and tracking after migration

Choose whether to retain an external embed or replace it with a WordPress integration. Check the destination account, required fields, consent text, success message and notification recipient. Supported imported HTML contact forms can submit in Free; GoHighLevel-specific embeds and automations need separate testing and configuration. Importing a page does not prove that leads reach the CRM.

## Give the client an editable WordPress workflow

Free handles importing, displaying and managing supported pages. [Tahmir AI Pro](https://www.tahmir.com/upgrade/) adds visual page editing, modules, logo detection/replacement, menu editing, advanced form management, SEO and client delivery tools. Use [Make HTML websites editable](make-html-websites-editable.md) to define editing scope and [Deliver client websites](deliver-client-websites.md) for the handoff.

Tahmir is independent of HighLevel; this is a page-import workflow, not a GoHighLevel account or CRM migration service.
