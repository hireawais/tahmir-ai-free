# Deliver client websites in WordPress after an HTML or AI build

Use Tahmir AI Free to import supported pages from the site your client approved, then review the result on the client's WordPress hosting. Pro adds the visual editing and client delivery tools when those are part of the project. Tahmir's [agency playbook for AI-to-WordPress delivery](https://www.tahmir.com/ai-to-wordpress-agency-playbook/) describes the wider process.

## Define the handoff before conversion

Record the approved source, required pages, integrations and acceptance criteria. Agree whether the client needs to change copy/images, edit menus, replace branding, manage forms or work with SEO fields. Set an owner for hosting, domains, backups and ongoing support.

Free importing is useful for an initial migration or publishing task. Visual editing and Tahmir's dedicated client delivery tools need [a licensed Pro add-on](https://www.tahmir.com/upgrade/).

## A reusable client-delivery checklist

- [ ] Import one representative page and approve its desktop/mobile result.
- [ ] Import the required pages and compare content, typography, imagery and spacing.
- [ ] Check navigation, buttons, downloads, external links and error routes.
- [ ] Test a real form submission and verify the intended inbox or CRM receives it.
- [ ] Review calendars, payments, login areas and other external integrations separately.
- [ ] Confirm the domain, redirects, canonical URLs, page titles, headings and image descriptions.
- [ ] Review scripts, tracking, consent controls, performance and accessibility.
- [ ] Set WordPress roles, backups, update responsibilities and a recovery process.
- [ ] Demonstrate one real client edit and save it before handing over access.
- [ ] Record approval, remaining tasks and who owns each item; publish after review.
