# Free HTML to WordPress converter plugin

Tahmir AI Free imports supported HTML websites into WordPress from an HTML ZIP or public URL. Use it when you have a finished front end and want to keep the approved design while moving page display and management into WordPress. See the official [free HTML to WordPress converter](https://www.tahmir.com/free-html-to-wordpress-converter/).

## Prepare an importable HTML website

Keep HTML pages, CSS, JavaScript, images and fonts together with the original relative folder structure. Include the entry HTML file and the assets it references. Build source projects first: a ZIP of React components, package files or an unbuilt Vite project is not a static HTML export.

For example, a simple export might contain:

```text
index.html
about.html
contact.html
assets/css/style.css
assets/js/site.js
assets/images/logo.png
```

## Convert HTML to WordPress for free

1. [Install the Free plugin](../README.md#download-and-install-the-free-converter-plugin).
2. Open **Tahmir AI → Import → Import HTML** and upload the ZIP.
3. Review detected pages and select the pages to import.
4. Check the WordPress result against the source at desktop and mobile sizes.
5. Follow navigation links and check images, fonts, buttons, scripts and contact forms.
6. Publish after reviewing the result on your WordPress hosting.

If the website is already public, use **Import from URL** instead. Start with one page that includes a hero, navigation, images and a form before scaling to the whole website.

## Make the HTML website editable after import

Free handles import, page display and management. For visual text/image editing, page modules, logo replacement and shared-menu changes, [upgrade to Tahmir AI Pro](https://www.tahmir.com/upgrade/). Keep Free installed; imported pages carry over. The output is managed by Tahmir and is not automatically a Gutenberg or Elementor rebuild.

Read [Make HTML websites editable](make-html-websites-editable.md) for the editing workflow and [Deliver client websites](deliver-client-websites.md) for a launch checklist. Backend applications and external integrations remain separate scope.
