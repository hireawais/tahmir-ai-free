Free HTML to WordPress and Lovable to WordPress importer for supported AI websites, public URLs and HTML ZIPs.

== Description ==

Tahmir AI Free is an open-source HTML to WordPress converter for supported static websites and AI-built pages. Start with a public URL or an HTML ZIP, review the imported pages, and publish them in WordPress without a Tahmir license.

= HTML to WordPress =
Upload a website ZIP with HTML, CSS, JavaScript and assets. Tahmir imports supported pages and rewrites supported local asset and page links.

= Lovable to WordPress and AI website imports =
Use the public deployed URL for a Lovable website, or supply a built static HTML export. The same workflow can be used for supported pages made with Bolt, Claude, Cursor, v0 and other AI website tools. React/Vite source code needs to be built and deployed first; source repositories and backend services are not converted into PHP.

Free includes URL cloning, HTML ZIP import, faithful page display and imported page management. It retains supported layouts and assets without requiring a Tahmir license.

The separate Tahmir AI Pro add-on includes the visual editor, page modules, form creation and editing, entry management and integrations, AI tools, client delivery, SEO, optional WooCommerce Revenue Insights and advanced modules. Keep Free active alongside Pro and activate a valid Pro license.

Free registers supported imported contact forms, accepts submissions and emails the site administrator. Form editing and entry viewing require Pro. Existing imported page content, form definitions and entries are retained so Pro can use them. Installing Pro does not require importing your pages again.

Import only websites and assets you own or have permission to reproduce. Dynamic applications and server-side behavior cannot always be recreated from public HTML.

== Installation ==

1. Install and activate Tahmir AI.
2. Choose URL cloning or HTML ZIP import from the Tahmir workspace.
3. Review and import your selected pages, then check the published result.
4. For visual editing and form management, install Tahmir AI Pro alongside Free and activate your license.

== Frequently Asked Questions ==

= What is included in Free? =

Website cloning, HTML ZIP import, faithful page display, imported page management and working imported contact forms. The visual editor, form editing and entry viewing require Pro.

= Do I need a license for Free? =

No. Free cloning, importing and page publishing do not require an account or license key.

= What happens when Pro is unavailable? =

Free importing, page display and imported contact form submission remain available. Editing and entry viewing require Pro. Existing page content and form data are retained.

== External services and privacy ==

URL cloning connects to the website you enter and downloads supported pages and assets. Imported resources may contact third-party servers when visitors load the page.

The plugin checks dash.tahmir.com for releases and downloads updates from the Tahmir release service backed by Amazon S3. Optional installation tracking is off until an administrator consents. It sends a random installation identifier, edition, plugin/PHP/WordPress versions and a daily activity signal. Consent can be withdrawn in Usage sharing settings.

Free and Pro store submitted form entries in your WordPress database. Free sends the site administrator a notification; Pro may send notifications or webhooks according to your configuration. Include appropriate information in your site's privacy policy.

Website privacy policy: https://tahmir.ai/privacy/
